# Claude 用量同步（浏览器扩展）

读取你**已经打开的** claude.ai 用量页上显示的“每周已用 %”，写入你自己的私密 Gist，规划器（电脑和手机）通过现有同步在约 20 秒内更新。
不调用任何 claude.ai 内部接口，只读页面上显示出来的数字。

## 安装（Chrome / Edge）
1. 打开 `chrome://extensions`，右上角打开“开发者模式”。
2. 点“加载已解压的扩展程序”，选择本文件夹（`extension`）。
3. 点工具栏的扩展图标，粘贴 GitHub 令牌（和规划器里用的同一个：Classic，只勾 gist），点保存。
4. 在这个浏览器里打开 claude.ai 的“设置 → 用量”页，把这个标签页**固定并一直开着**。
5. 图标上的徽章显示当前读到的百分比：绿色 = 已同步，橙色 `?` = 读不到数字，红色 `!` = 令牌或写入有问题。

## 重要限制
- 页面本身不会自动刷新，所以扩展每隔几分钟（默认 3 分钟，可在弹窗里改，0 = 不刷新）点一下页面自带的刷新按钮，找不到按钮时才重新加载标签页。要“实时”就必须保持这个标签页开着；关掉后数字就停在最后一次。
- 如果你同时登录了备用 Claude 账号，并在那个账号的用量页上读数，会把备用号的数字写进来。请只在主号的页面上保持开着。
- 扩展只在 `https://claude.ai/settings/*` 上运行。如果用量页不在这个路径下，请改 `manifest.json` 里的 `matches`。
- 读不到、或页面上有多个无法区分的每周数字时，扩展**不会写入**，弹窗里“诊断信息”会列出它看到的内容。
- 是否符合 Anthropic 服务条款我无法替你判断：它只读你自己打开的页面，但定时自动刷新属于自动化行为，请自行确认。

## 工作方式
- 只在页面数字**发生变化**时才写入，所以你在规划器里手动加减不会被立刻覆盖。
- 写入时保留规划器里设置的重置时间（dow/hh/mm），只更新 `used` 和 `ts`。
